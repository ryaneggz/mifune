## Key Capabilities Mentioned
The agent supports multiple platforms: "Telegram, Discord, Slack, WhatsApp, Signal, Email, CLI — and a growing list of platforms." It features persistent memory, skill auto-generation, scheduled task automation, subagent delegation, container sandboxing across five backends (local, Docker, SSH, Singularity, Modal), web/browser control, and multi-model reasoning.
